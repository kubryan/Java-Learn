# Python 基礎勘誤練習

這些範例不是直接複製原 HackMD 的程式碼，而是依 Python 3 官方文件重寫，並保留原本「輸出 → 型別 → 判斷 → 迴圈 → 字串」的練習節奏。

| 檔案 | 練習重點 | 執行方式 |
|---|---|---|
| `corrected_basics.py` | `print`、型別、f-string、`//`、`-=`、`if`、`range`、字串切片與編碼 | `python corrected_basics.py` |
| `input_and_loops.py` | `input()`、型別轉換、while、continue | `python input_and_loops.py` |

請使用 Python 3。先執行原樣範例，再每次只改一個值並觀察輸出；遇到 `ValueError` 時，回到「輸入與型別」筆記確認程式當下拿到的是 `str` 還是數字。
