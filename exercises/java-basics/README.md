# Java 基礎練習

這個資料夾刻意不使用 Gradle、Maven 或框架。目標是先看懂一支 `.java` 程式如何被編譯和執行。

| 檔案 | 練習重點 | 建議修改 |
|---|---|---|
| `HelloJava.java` | 類別、`main`、字串輸出 | 改變名字與第二行訊息 |
| `ShoppingCart.java` | 變數、條件、方法、回傳值 | 嘗試加入滿額折扣或免運規則 |
| `CorrectedBasics.java` | 型別轉換、陣列、條件、switch 與方法 | 嘗試新增一個成績等第分支 |
| `ReadAge.java` | Scanner 輸入格式驗證 | 輸入整數與非整數各測試一次 |
| `Profile.java` | private、getter、setter 與 this | 嘗試拒絕空白名稱以外的不合法資料 |

請先依根目錄 README 的指令編譯。每次修改後都重新執行 `javac`；若出錯，先讀第一條錯誤訊息指出的檔案與行數。
