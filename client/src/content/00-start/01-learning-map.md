## 本章目標

你不需要在第一天決定自己最後要做網站、桌面工具還是 Minecraft 模組。現在只要理解：**這三條路都會用到同一批 Java 基礎**。先把共同地基打好，之後選哪一條路都不會白學。

## 這個基地怎麼用

每篇筆記都有概念、完整範例、練習、常見錯誤與複習提示。第一次閱讀時，先照著範例打一遍；第二次回來時，優先看「常見錯誤」和程式碼旁邊的說明。右側的「標記完成」只保存於目前瀏覽器，Markdown 原稿則永遠保存在 `client/src/content/`。

| 階段 | 你會練到什麼 | 可做出的成果 |
|---|---|---|
| Java 基礎 | 變數、判斷、迴圈、方法 | 命令列計算器、小遊戲 |
| 核心與物件導向 | 類別、集合、例外、檔案 | 有資料保存的小工具 |
| 桌面工具 | 視窗、事件、檔案選擇 | 檔案整理器或筆記工具 |
| 後端 API | HTTP、JSON、CRUD | 學習進度 API |
| Minecraft | 註冊、事件、資源、side | Fabric 與 NeoForge 的小型模組 |

## 今天的行動

1. 打開「環境準備」並確認你能在終端機執行 `java --version`。
2. 完成第一個 `HelloJava`，先感受「編輯 → 編譯 → 執行」的循環。
3. 不懂的名詞先標記，不必立刻背起來。程式設計是反覆回來查的技能。

> 你不需要記住所有語法；你需要知道遇到問題時，應該回到哪一個座標查。

## 複習速查

- Java 是一種需要先編譯，再執行的程式語言。
- 一個小作品比讀完十篇沒有動手的教學更能暴露真正不懂的地方。
- 先完成基礎與物件導向，再進入框架或模組 API，會比較容易理解錯誤訊息。
